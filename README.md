# claude-experiments

## Voice Is the OS

A recap and marketing case study of the ElevenLabs Summit in New York (11.11.2026), read through a financial-services lens. Built as an "album": a scroll-drawn signal ribbon, a now-playing bar, a carousel of release covers, photos from the room, and narration you can play.

- Page: [`voice-is-the-os/index.html`](voice-is-the-os/index.html)
- Live (once GitHub Pages is on): https://nativeeridian.github.io/claude-experiments/voice-is-the-os/
- Narration: `python3 voice-is-the-os/tools/narrate.py --help` (ElevenLabs; writes `voice-is-the-os/audio/`)
